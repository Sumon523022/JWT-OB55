# JWT-OB55

A Python Flask application featuring JWT authentication, configured for seamless deployment on Vercel.

---

## 📁 Project Structure

```text
JWT-OB55/
├── app.py              # Main Flask application file
├── requirements.txt    # Python dependencies
├── vercel.json         # Vercel deployment configuration
└── README.md           # Documentation

```

---

## 🚀 Features

* **Flask Backend**: Lightweight Python web framework.
* **JWT Authentication**: Json Web Token implementation for secure user authentication.
* **Vercel Ready**: Pre-configured with `vercel.json` for serverless deployment.

---

## 🛠️ Setup and Installation

### Prerequisites

* Python 3.8 or higher
* `pip` (Python package manager)

### Local Development

1. **Clone the repository / Extract files**:
```bash
git clone https://github.com/Sumon523022/JWT-OB55.git
cd JWT-OB55

```


2. **Create a virtual environment**:
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

```


3. **Install dependencies**:
```bash
pip install -r requirements.txt

```


4. **Run the application**:
```bash
python app.py

```


The application will run locally at `http://127.0.0.1:5000/`.

---

## ☁️ Deployment on Vercel

1. Install the Vercel CLI:
```bash
npm install -g vercel

```


2. Deploy from your project directory:
```bash
vercel

```


3. Follow the on-screen prompts to complete the deployment.
